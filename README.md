# Crucible

A conversationally grown physical world for systems play.

Crucible begins small on purpose. Conversation supplies consequential intent; source is the inspectable implementation surface; executable candidates supply evidence; Git preserves lineage.

The project inherits proven construction and publication mechanics from Accessibility without inheriting its domain ontology. Foundry is behavioral evidence, not source lineage.

See `SEMANTIC_SURFACE.md` for the few present-tense constraints that currently deserve authority.
